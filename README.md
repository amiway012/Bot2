# Bot2
#Данное приложение разработано для приёма и обработки сообщений коллективной командой, а не отдельным лицом. Бот обладает расширенными функциональными возможностями: реализована система капчи для верификации пользователей, предусмотрен механизм фильтрации флуда, ведётся статистика по входящим сообщениям, а также доступна функция генерации административных приглашений.

В перспективе планируется реализация дополнительных функций, включая категоризацию сообщений и автоматическое формирование краткого резюме запросов пользователей.
