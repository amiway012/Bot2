# Bot2
Данный бот разработан для приёма и обработки сообщений коллективной командой, а не отдельным лицом. Бот обладает расширенными функциональными возможностями: реализована система капчи для верификации пользователей, предусмотрен механизм фильтрации флуда, ведётся статистика по входящим сообщениям, а также доступна функция генерации административных приглашений.Таким образом он оптимизирует такую простую на первый взгляд задачу, экономя время менеджера 

В перспективе планируется реализация дополнительных функций, включая категоризацию сообщений и автоматическое формирование краткого резюме запросов пользователей.
